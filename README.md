# ふたつの灯 v2.5 — Two Lanterns

v2 に難易度と新しい敵を加えたバージョン 2.5。

二人で協力して地下迷宮を進む、ブラウザで遊べるオンライン協力アクション。
離れた場所の友達とも、**ルームコード**を伝えるだけで一緒に遊べます。

## 遊び方

| 操作 | キー |
| --- | --- |
| 移動 | W A S D |
| 攻撃（長押しで連続） | 左クリック |
| 回避（無敵） | Space / 右クリック |
| スキル | Q / E / R / C |
| 拾う・宝箱を開ける | F |
| キャラクター画面（装備・スキル習得） | Tab |
| 操作説明 / 音 | H / M |

- 一人が「ルームを作る」→ 画面右上の 5 文字のコードを相方に伝える
- 相方は「参加する」にコードを入れる（`https://…/?room=コード` のリンクでも入力済みで開けます）
- フロアの魔物を全滅させると転移陣が開く。二人で乗ると次の層へ。3 層ごとにボス
- 宝箱・敵から武器（6 種 × 5 レアリティ＋特殊効果）とスキルの巻物（7 種）がドロップ
- 倒れても相方がそばに立てば復活

## 育成

- ジョブは 5 種類（剣士・弓使い・魔導士・癒し手・影の刃）。ジョブごとにスキルツリーがあり、2 つの大分岐と、それぞれ 2 つの最終ジョブ（全部で 4 つ）から 1 つを選びます
- 武器は同じ武器種・同じレアリティを集めて合成（コモン 5 本 → アンコモン 4 本 → レア 3 本 → エピック 2 本 → レジェンド 2 本 → 神話）
- 防具は 5 か所。セットは 2 個と 4 個で効果が出ます
- 石碑のなぞなぞと光る台座を解くと報酬がもらえます

## 保存

進行状況はジョブと難易度ごとに自動で保存され、同じブラウザなら続きから遊べます。タイトルの「書き出し／読み込み」で別のブラウザにも移せます。

胞子キノコ / 大胞子キノコ / 石翼のインプ / 錆鎧 / 蝋燭の祈祷師 / ボス：苔の巨像

## v2.5 で変わったこと

v2（`two-lanterns-v2`）とは別のゲームとして公開しています。保存データも別で、v2 のデータには読み書きしません。

- 難易度：平和 / 少し難しい / 鬼。保存データはジョブと難易度ごとに分かれます。二人で遊ぶときの敵の強さは、ルームを作った人の難易度に合わせます。
- 鬼：敵の体力 3.6 倍、攻撃 2.3 倍、数 1.45 倍。巻物は半分、スキルポイントは 6 割の出やすさ。宝箱はレア以上、ボスはエピック以上を落とし、ボスは上級巻物（一度に +2〜+3）も落とします。
- 色違い：蒼は素早い、翠は硬い、紅は凶暴。
- 新しい雑魚：影喰い狼、爆ぜ火、棘吐き花、酸袋ガエル、鉄甲虫、仮面の刺客。
- 新しいボス：蝕みの女郎蜘蛛、燭台の大司教、鉄角の暴獣、深淵の大目玉。3 層ごとに順番に現れ、2 周目以降は色が変わります。

### 追加要素

- 攻撃：クリックで通常攻撃、長押しで溜めて重撃。武器ごとに重撃の形が違う。
- 合成：防具は同じレアリティなら部位を問わず合成でき、部位とセットはランダム。神話まで。武器は神話 5 本で武器種ごとに 1 振りの「唯一」になる。
- 鬼だけ：各ジョブの最終ジョブが 6 つに増える。2 層ごとに商人が来て、コインの買い物と呪いとの交換ができる。
- 召喚師：武器・防具・重撃なし。生き物を呼んで戦う。
- ペット：卵から孵る。12 種族 × 6 属性。キャラクター画面に専用タブ。
- 隠し部屋：鍵を見つけると扉が開く。宝物、コイン集め、泉、商人のどれか。
- 異次元：ボスを倒すと紫の転移陣が開く。天気ごとに効果が違い、宝箱が多い。
